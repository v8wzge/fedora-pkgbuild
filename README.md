# v8wzge Fedora RPM repository

This branch is served by GitHub Pages and holds the automatically built RPM
packages for https://github.com/v8wzge/fedora-pkgbuild.

- `x86_64/` — binary RPMs
- `noarch/` — architecture-independent RPMs
- `SRPMS/` — source RPMs
- `state/` — last-built upstream commit / release fingerprint per package
- `repodata/` — generated by `createrepo_c` on every build

Client configuration: `v8wzge-fedora.repo` (also available on the `main` branch
under `repo/`). Packages are unsigned, so the repo uses `gpgcheck=0`.
